# 当前系统说明

维护日期：2026-10-30。以下说明当前默认入口，历史文档不覆盖本文和通用协议。

## 三种模式

| mode | 入口与实现 | 教学与测评 |
| --- | --- | --- |
| chat | 默认网页 ChatApp；后端 chat_classroom.py | 模型生成任意课题计划/讲授/测评，结果未经过通用核验 |
| classic | API 不传 mode 时的兼容默认值；lesson.py | 预设行列式课程，Fraction 精确验证与确定规则 |
| planner | API 显式创建；planner.py + 旧课堂 | 模型提出受限工具调用，只有行列式课程可执行 |

旧页面源码位于 LegacyClassroom.tsx，并非当前网页入口。旧版分段 protocol=2 不属于通用聊天协议。

## 当前链路

React ChatApp → FastAPI 事件接口 → chat_classroom → 教学安排/专项 Agent → tutor 模型适配器 → SQLite 原子保存。模型请求在锁外；按 job id 判断过期后提交。SSE、可主动取消的网络请求、持久任务队列尚未实现。

新学习默认先展示初始化卡片，收集学习主题、目标与阶段，并按目标展开教材/考试补充项。`chat_intake` 事件将结构化自述持久化为 `profile.intake`，交给安排 Agent 形成初步计划或追问，首次不会直接讲课/测评。用户可以跳过卡片直接聊天；旧会话继续恢复。详细字段与边界见通用 Agent 协议中的初始化卡片章节。

通用 Agent 的结构化交接详见 HANDOFFS.md；反馈通过 handoffs 直接进入下一轮上下文，不只依赖聊天文本。用量通过 usage.py 独立写入 model_usage.sqlite3，不随课堂回滚；详见 COST_TRACKING.md。

左侧顶部的安排 Agent 调试独立展示模型实际请求与原始工具回复，保存到 model_debug.sqlite3，每会话保留最近30次，按原会话凭据鉴权。请求与回复经过密钥/私有字段脱敏，不展示内部推理；失败与被替代的安排调用也保留，不回灌给模型。详见 PLANNER_DEBUG.md。

授课正文提交后，独立调用通俗讲解 Agent，先定位原文中可能难懂的句子，返回简短难点说明和解释。原句高亮，用箭头连接右侧独立小卡片，随各段授课滚动；最多3条批注，允许无额外难点时返回0条，合计解释文本不超过300字，例子按需展开。辅助记录存 plain_language.sqlite3，format_version=2，旧结果可继续显示或手动升级。按源授课消息关联、去重和重试，故障不回滚课堂，也不修改 revision/进度/证据。见 PLAIN_LANGUAGE_AGENT.md。

## 教学边界

计划进度与测评证据分开。学生确认理解会推进大纲；讲授完成不自动记作掌握。当前通用测评来源是 model_judgment。报告主要保存计划、证据和讲授记录，尚非完整的个性化总结生成器。最近24条对话、12条证据及8条当前计划交接用于模型上下文，非长期认知档案。

## 本地运行与可靠性

React/TypeScript/Vite/KaTeX，FastAPI/SQLite。匿名恢复令牌鉴权、版本冲突、事件幂等、任务过期保护、重启中断恢复。进程内任务在重启时不会继续执行；旧网络请求被替代不等于请求停止。用量的 completed 表示模型调用及解析完成，不代表整轮教学通过所有校验。

自动测试和构建命令见 README；测试结果以当前运行记录为准，不在多份文档重复维护测试数量。真实教学效果、长期保持和外网生产运行尚未验证。
