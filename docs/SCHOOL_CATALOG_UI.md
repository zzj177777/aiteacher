# 学段与学科课程入口

课程入口包含两条路径：① 学段 → 科目 → 自由开始学习，可实际聊天规划与讲授；② 科目 → 年级 → 上下学期，仍是课程筹备占位页，单元与小节尚未配置。新入口不嵌入教材链接或 PDF，自由小课也不声称依据教材正文。

## 页面与配置

- `src/schoolCatalogData.ts`：三个学段、年级、科目配置及恢复参数校验。小学仅语文、数学、英语；初中和高中均为语文、数学、英语、物理、化学、地理、生物学、政治、历史，合计 21 个学段科目入口。小学六个年级，初高中各三个年级。初中政治沿用稳定 ID `ethics`，高中沿用 `politics`，均显示为“政治”。
- `src/SchoolCatalog.tsx`：课程中心的学段切换、科目搜索，以及科目年级页、学期占位页、面包屑与前后学期导航。已移除无对应科目的综合素养分类筛选。
- `src/school-catalog.css`：响应式布局和不同学科配色；真实按钮可键盘操作，有焦点和选中状态，遵循减少动画偏好。
- `CourseLibrary.tsx`：在课程中心展示入口；长期课程、历史会话和原有资料库独立保留。

科目和学期目前都是导航位置，**不是经过教材或地区课程表核验的实际开课范围**。例如英语起始年级、初中物理化学开课时间、高中选科及必修/选择性必修册次，需在后续课程配置时细化。高中“上/下学期”仅表示时间，不等于教材上/下册。不要从这些占位卡片推断真实章节或学生掌握状态。

## 导航与后续接入

使用现有 `aiteacher.learning.navigation.v1`，新增 `view=school`，记录 `stage_id`、`subject_id`、可选 `grade_id` 和 `term=1|2`。首页 `view=library` 也记录当前学段。刷新恢复选择；非法科目回首页，非法年级或学期回对应科目的年级列表。浏览目录不创建课堂或调用模型；明确点击“自由开始学习”才创建聊天课堂，后续发送消息或请求选项才调用模型。

旧 `primary` / `primary-semester` 书签仍可恢复历史小学数学页；首页入口已改为新的全学段导航。原资料库移至课程中心顶部「资料库」按钮，文件与 API 保留，新的学科/学期页面不嵌入资料库链接。

后续以稳定的 `stage + subject + grade + term` 位置接入具体课程配置，再按地区/教材系列/版次定义真实单元和小节。不要把当前静态简介当作教学大纲。已存在的用户长期课程 ID、课堂 ID 与此入口体系分别管理，实际关联时应显式保存映射。

学期目录浏览不需要后端规划；自由小课通过现有聊天 API 保存上下文与会话，详见 [学科自由小课](SCHOOL_FREE_LEARNING.md)。具体年级和教材不能从学段或占位学期推断。
