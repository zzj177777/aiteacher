# 小学数学入口

> 历史入口兼容说明：课程中心主入口已扩展为[全学段学科导航](SCHOOL_CATALOG_UI.md)。本文描述的旧小学数学页面仅用于恢复已有书签，仍可查看历史资料；新学科入口采用独立的前端框架，不连接课本或 PDF。

当前实现课本导航与官方教材资料索引，教材系列由用户选择为人教版。未接入真实章节目录，不生成或展示推测的课本章节。

- 课程中心提供“小学数学”入口。
- 一至六年级各有上册、下册，共12个入口，均可进入对应学期页。
- 学期页展示年级、册次、学科和版本，提供上一册/下一册、全部年级和课程中心导航。
- 章节区明确标记“章节目录待接入”。点击导航不会新建课程、课堂、规划任务或调用模型。

实现：`src/PrimaryMathCatalog.tsx`（入口组件、12项稳定目录数据和学期页）、`src/primary-math.css`（响应式布局）。`CourseLibrary.tsx` 接入首页入口和导航恢复。

目录ID为 `primary-math-g{1..6}-t{1..2}`。原 `aiteacher.learning.navigation.v1` 新增 view=primary / primary-semester，后者保存 semester_id。刷新后恢复原入口；非法或过期学期ID回到年级列表。

教材资料库通过后端只读接口 `/api/materials` 读取精选书目和可用本地文件，无数据库变更。每个学期可查看本地历史教材 PDF（阅读/下载）与官方当前目录入口，二者版本分开标记；具体版次以版权页为准。PDF 文件已保存，正文检索和真实章节目录尚未接入。详见 [教材资料库](TEXTBOOK_LIBRARY.md)。章节到教学会话的关联将在接入真实目录时单独实现，不能把当前课程模型生成的路线当作课本目录。
