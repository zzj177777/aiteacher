## 启动

需要 Python 3.10+、Node.js 20.19+ 或 22.11+。在项目目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

脚本创建项目虚拟环境、安装依赖并构建页面。打开 http://127.0.0.1:8000 。仅绑定本机，尚未配置外网部署。

手动开发：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm install
```

在两个终端分别运行：

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
npm run dev
```

开发页面：http://127.0.0.1:5173 。API 文档：http://127.0.0.1:8000/docs 。生产构建使用 `npm run build`，重启后端以挂载构建资源。

## 可用功能

新增分段讲授：一个要点一段讲解，随堂检查后继续或补讲换题；会话保存已完成要点、历次检查与待解决疑问，可暂存并恢复。报告与笔记包含随堂轨迹，检查通过不计为独立掌握。详见 `docs/SEGMENTED_TEACHING.md`。

新增：明确任务驱动的授课 Agent。诊断后由状态机派发知识点、目标与诊断重点；授课完交回调度器，学生继续练习。聊天窗口用“调/授/评”区分角色，显示可折叠的任务与交接记录。现有课堂可在知识点下拉菜单中请求授课；详见 `docs/LECTURER_AGENT.md`。

- 三题起点诊断；逐条规则反馈；引导消元练习。
- 倍加、换行、缩放；整数/分数/有限小数的精确计算；允许不同合法路径。
- 学生自己输入受影响行；错误结果不改变当前矩阵。
- 普通题与换行题的独立测验；提示/学科问答转为辅导并换题复测，当前题库用尽则如实结束。
- 两道规则辨析、个人说明笔记；说明保存但不自动评分。
- 课后轨迹、错误修正、可下载 Markdown 笔记；刷新恢复课堂。
- 匿名会话令牌校验、SQLite 持久化、事件幂等和版本冲突保护。

独立完成指未请求解题提示或学科问答，允许系统逐步正确性反馈，不等于考试的一次作答成绩。通用规则卡在所有阶段均可查看。诊断和规则辨析采用选择题，不能单独证明深度理解。本次达标也不代表已验证长期保持。

## 可选模型问答

复制 `.env.example` 为 `.env`，填写支持 Chat Completions 格式的完整接口 URL、API key 和模型名，然后重启后端。密钥仅服务端读取，不要放入前端变量或提交到仓库。

未配置时明确显示规则教学模式，提供倍加、换行、缩放、三角形求值的预设解释；不能声称具备通用 AI 诊断能力。配置后启用后台 AI 问答，失败保留规则回复；旧请求不能覆盖新课堂步骤。调用外部模型时会发送当前问题、矩阵及最近六条课堂消息，不发送会话凭据。

模型负责任务驱动讲授和问答；核心教学调度、数学评分和报告采用确定规则。尚未接入模型对自由文字解释的可靠评分，也没有训练学生认知模型。问题关键词匹配属于初步回补，不等于经过验证的深层错因诊断。

```powershell

```

测试覆盖精确数学不变量、错误操作、完整学习路径、提示后的独立性、题库耗尽、规则辨析、真实 HTTP 鉴权/恢复/幂等/冲突/原子性。无需真实模型或额外测试依赖。

## 目录

- `backend/math_engine.py`：精确有理数与行变换验证。
- `backend/content.py`：10 道审核题与诊断题。
- `backend/lesson.py`：课堂状态机、证据与报告。
- `backend/tutor.py`：规则回复与可选模型适配器。
- `backend/app.py`：API、SQLite 与异步问答任务。
- `src/`：React 课堂、报告与响应式样式。
- `data/`：本机运行生成的数据库，不提交版本控制。

浏览器保存最新课堂的恢复凭据，数据库保存在本机 `data/classroom.sqlite3`。开始新课堂会替换浏览器入口；建议先下载报告。跨会话尚不追踪已见过题目，因此新一轮不是长期保持测验。
