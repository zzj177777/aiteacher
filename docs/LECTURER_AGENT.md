# 授课 Agent 与课堂协作

> 本文记录初版整段讲授设计。当前分段实现与后续开发协议以 [授课 Agent 开发文档](LECTURER_AGENT_DEVELOPMENT.md) 为准。

2026-10-21

## 职责

授课 Agent 不是自由调度者，也不只是被动问答。状态机将指定知识点的教学任务派给它，它按目标讲授，结束后交回调度器，由学生选择继续原课堂任务。

真实参与者：课堂调度器（状态机）、授课 Agent（DeepSeek；失败时规则讲稿）、测评模块（程序规则）。界面明确标注来源，不将程序模块伪装为独立模型。展示的是任务、输出、结果与交接，不展示隐藏推理过程。

## 任务协议

每项任务包含 id、from_agent、to_agent、topic、title、objective、outline、focus、reason、constraints、return_phase、status、message_id。知识点限定为整体三角化方法、倍加与缩放、换行与符号、三角形求值。

授课 Agent 接收任务和当前矩阵、修正系数、最近错误观察；不获得模型密钥以外的其他凭据，不获得修改课堂和测评的工具。输出为学生可见中文讲解，模型不决定下一阶段或是否掌握。

## 流程

三道起点诊断 -> 状态机派发整体方法任务（附需要补充的规则） -> lecture 阶段 -> 授课 Agent 生成讲解并交接 -> 学生点击继续 -> 恢复 guided_practice。

学生在练习、独立测验或规则辨析阶段也可请求指定知识点讲解。调度器保存原阶段与题目；讲完恢复。独立题中请求授课自动记录为接受帮助，后续需要新题复测。

后台模型结果绑定任务 ID 和课堂版本。生成失败或过期时保留本地讲稿；结束课堂取消待处理任务；服务重启恢复未完成生成，避免无限等待。不存在任务的历史消息标为旧版记录，不追溯声称由某 Agent 生成。

## 界面

- 调：紫色，课堂调度器，来源为状态机。
- 授：绿色，授课 Agent，区分 DeepSeek、准备讲授、规则讲稿、规则回退。
- 评：金色，测评模块，来源为程序规则。
- 任务与交接以独立卡片显示来源、接收方和任务短 ID；可关闭显示。
- 授课阶段左侧显示目标、提纲、诊断重点与任务边界；右侧显示实际讲授及问答。

## 验证

31 项测试通过，包括真实 HTTP 派发/恢复、任务内容、模型上下文、模型失败、过期结果、重启恢复、独立性和完整课堂回归。TypeScript 与 Vite 构建通过。
