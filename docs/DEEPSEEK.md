# 模型接入与调用边界

适配层：backend/tutor.py，使用 Chat Completions 兼容接口。AI_API_URL 为完整路径，AI_API_KEY、AI_MODEL 由服务器 .env 读取；本文不固定供应商当前模型或报价，以实际配置为准。

DeepSeek 域名请求设置非思考模式；当前非流式，45秒超时。普通 complete 默认1024输出token，选中解释500，工具调用2000。返回截断会明确报错，不自动放宽上限或无限重试。

当前 chat 模式中，安排、讲授、出题、评判均调用模型；不是仅自然语言答疑。传入学习目标、计划、最近对话/证据和交接等信息，不传恢复凭据。评分标准仅按角色需要提供，不能公开在消息或交接中。详细范围见 CHAT_AGENTS_DEVELOPMENT.md。

旧 classic/planner 模式使用受限课程、精确验证及部分规则回退，与通用模式不同。通用模型失败回滚本轮并保存诊断，不伪造规则讲稿。调用原始响应的 usage 供独立用量记录，费用按配置价格估算；见 COST_TRACKING.md。

密钥只在服务端使用，不写入前端、日志或开发文档。更换配置后重启。供应商错误及公式约定见 ERROR_DIAGNOSTICS.md。
